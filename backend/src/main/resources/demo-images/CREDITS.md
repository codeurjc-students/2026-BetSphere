# Demo image credits

All images in the seeded catalog were created for the BetSphere demo.

| Assets | Origin |
| --- | --- |
| Football, basketball and tennis icons | Ball illustrations generated with OpenAI ImageGen. |
| Club and competition badges | BetSphere designs using plain initials, geometric shapes and accent colors. |
| Rafael Nadal and Carlos Alcaraz badges | BetSphere monogram designs using `RN` and `CA`. |

The catalog uses club, competition and player names to identify its demo entries. BetSphere is an academic project with no affiliation with or endorsement from those organisations or players.

The Docker image bundles the demo artwork above. Official crests, league logos and player photographs are excluded from the bundled catalog. See the repository [LICENSE](../../../../../LICENSE) for the project licence.

The [stadium background](../../../../../frontend/public/matchday-pitch.jpg) used on the home, sign-in and registration pages was generated with OpenAI ImageGen for BetSphere. It depicts a fictional football stadium.
